# cuda
执行下面命令
```sh
/tmp/cuda_12.8.0_570.86.10_linux.run --toolkit
```

> [!danger] 注意，在 cuda版本和 driver版本不匹配的情况下，需要在
> ```
> x CUDA Installer se Agreement                                                  x
   x - [ ] Driver                                                                 x
   x      [ ] 570.86.10                                                           x
   x + [X] CUDA Toolkit 12.8                                                      x
   x   [X] CUDA Demo Suite 12.8                                                   x
   x   [X] CUDA Documentation 12.8                                                x
   x - [ ] Kernel Objects                                                         x
   x      [ ] nvidia-fs                                                           x
   x   Options                                                                    x
   x   Install         
> ```
> 将Driver 这个选项取消
# nccl

在  [nccl github](https://github.com/nvidia/nccl) 下载 最新的 upstream nccl 编译安装。
编译命令:

```
# 解压源码包，进入源码包
编译命令
make pkg.debian.build -j 70
```

安装命令:
```
dpkg -i  build/pkg/deb/libnccl*.deb
```
# nccl-test
在 [nccl-test github](https://github.com/nvidia/nccl-tests) 下载最新的upstream nccl test 编译测试。
编译命令:
```
make MPI=1 MPI_HOME=/usr/lib/x86_64-linux-gnu/openmpi  CUDA_HOME=/usr/local/cuda-12.8 NCCL_HOME=/usr/lib/x86_64-linux-gnu -j 70
```
