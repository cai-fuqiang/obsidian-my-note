## 前言

这篇文章要介绍一套简单、能够提升行动力与产出成果的笔记分类架构— PARA，分别是代表了：

- 项目
- Areas of responsibility (下方讲解均简称 Area)
- 资源
- 档案

这套架构是由生产力专家— Tiago Forte 所提出，有以下 5 点特色让我觉得很棒：

- **泛用性** ：适用在任何型态的资源，你不但可以用在笔记软体、也可以用在云端硬碟、个人电脑的档案分类。
- **行动性** ：笔记不再只是死板的资讯，而是可以让你知道下一步的行动是什么。
- **产出导向** ：分类的目标是提升你的产出能力。
- **可缩放性** ：可以让你依据需求调整检视笔记内容的颗粒度，可以快速总览也可以深入细节。
- **机动性** ：可直接从既有的笔记开始使用，不需要大幅颠覆整个既有的笔记系统。

以上的特点有经过我自己的理解稍加修饰，翻译成更好理解的说明。

## 一、为什么我觉得这套架构好用？

在采用 PARA 架构前，我们必须先了解「笔记/文件/档案分类」会遭遇的问题，才能体会 PARA 的价值。

### 1\. 整理笔记时一定会碰到的难题— 怎么分类？

不论在文件、笔记或是档案的分类上，我们都会碰到同样的难题：「我该如何分类？」

这个议题我曾在《 [如何对文件及笔记进行编码分类？结合六个领域的知识来整理笔记](https://medium.com/pm%E7%9A%84%E7%94%9F%E7%94%A2%E5%8A%9B%E5%B7%A5%E5%85%B7%E7%AE%B1/%E5%A6%82%E4%BD%95%E5%B0%8D%E6%96%87%E4%BB%B6%E5%8F%8A%E7%AD%86%E8%A8%98%E9%80%B2%E8%A1%8C%E7%B7%A8%E7%A2%BC%E5%88%86%E9%A1%9E-a25e3f4f92c4) 》的「管理咨询」中提到分类原则：

> ***若我们将*** [***MECE 理论***](https://meet.bnext.com.tw/articles/view/39530) ***套用到笔记分类、文件分类上，就是确保分类之间不要互相重叠，且每种类别都要涵盖。***
> 
> ***原理是这样说，实际上在用的时候只要抓大原则即可。我们要注意：  
> 1\. 最上层的分类以4–7 个为极限，愈多对于讯息处理愈不利。  
> 2\. 当分类太多的时候，要将同类主题进行合并。  
> 3\. 先用树状图或列点纪录，再对笔记系统进行分类。***

当时我建议对笔记系统采取「每层4–7 个主题」的分类方式，只要该层级超过7 个主题就要进行分层，最后可以得到一个文件/笔记的树状结构(下方为示意图)。

![](https://miro.medium.com/v2/resize:fit:1304/format:webp/0*K9eki7haZ63dPwNN.png)

笔记架构分层

### 2\. 采用「主题」分类笔记时会碰到的问题

这套架构我使用了大约2个月的时间，我逐渐发现一个严重的问题：「这套架构无法让我产生有效的行动」。

什么意思呢？

事实上我们写下的笔记，只有少数的笔记我们会花时间更新与维护; 而大多数都不会再被看第二遍，更不用说在上面记录待办清单、思考过程。

例如最近老板叫你对 A 专案进行规划，于是你会建立一则「A 专案」的笔记，透过 [厘清专案目标、拆解行动清单](https://medium.com/pm%E7%9A%84%E7%94%9F%E7%94%A2%E5%8A%9B%E5%B7%A5%E5%85%B7%E7%AE%B1/%E7%82%BA%E4%BB%80%E9%BA%BC%E8%A8%82%E4%B8%8B%E7%9B%AE%E6%A8%99-%E5%8D%BB%E7%B8%BD%E6%98%AF%E9%9B%A3%E4%BB%A5%E9%81%94%E6%88%90-4a25ed01d5d9) ，逐步推进专案进度。

也就是说：

> ***「A 专案」笔记会比其他笔记的「行动性」来得高，它能够让我们产生行动。***

### 3\. 多数的笔记不具有「可行动性(actionable)」

你可能会好奇：对笔记进行「主题分类」，没办法让笔记具有「行动性(actionable)」吗？

答案是：很难做到。

以我自己举例：

```c
我在年初透過 OKR 規劃了一整年的個人專案，範圍包括了增進和家人間的關係、提升自己的職涯技能、精進自己的個人嗜好與興趣…等。每個專案又可以拆分成數個子專案，例如在提升自己的專業技能上：
- 舉辦 5 場專業技能分享講座
- 考取 PMP 證照
- 學習 5 堂跟自己專業有關的線上課程
...
```

这么多的子专案同时进行，我必须藉由多则不同的笔记来管理规划与进度。

然而人的专注力是有限制的。在现实生活中，我一段时间( 2–3 个月) 只能专注在1–3 个子专案，其他的子专案笔记可能1 个月都不会开启一次。

此时旧的笔记分类方式就出现了问题…

如果我单纯按照「主题」的方式来分类笔记，当我要寻找这1–3 个子专案的笔记时，就会变得非常麻烦。

例如我要找「PM 技能分享讲座」的相关笔记时，我必须到「商学」>「产品管理」>「PM 技能」去找，整个步骤非常冗长; 而其他在「商业」分类下的主题笔记，例如「产业分析」、「经济学」…等就不这么重要。

### 4\. 让笔记帮助我们变得更有「行动力」

那该怎么办呢？

我们不妨转变思考，将与专案相关连的笔记直接放在一起即可。

例如我将「PM 技能分享讲座」当作是一个专案资料夹，并且把相关的主题笔记(例如「PM 技能」、「专案管理」、「时间管理」…) 都放到该资料夹下，未来寻找笔记就变得有效率许多。

这告诉了我们一个重要的笔记分类原则：

> ==***将具有「可行动性」的笔记放在一起，就能大幅地提升我们的行动力。***==

而这也是 PARA 分类架构最大的优点。

## 二、PARA 这套架构如何运作

先看一张 Tiago Forte 解释 PARA 的图片：

![](https://miro.medium.com/v2/resize:fit:1400/format:webp/0*PC4DOCJuHP5_oJW-)

图片来源：《 PARA 方法：组织数字信息的通用系统 》

他将笔记分类拆分成4 大块：

- **Projects (专案)** ：指那些「有时限」以及为了「产出特定成果」的工作，通常是为了达成某个目标(goal)。
- **Areas of responsibility (领域)** ：指那些需要你长时间关注的领域，依据每个人专注的领域而有所不同。
- **Resources (资源)** ：指那些你感兴趣的主题、嗜好。
- **Archives (封存)** ：不属于以上 3 类，通常是已经做完的专案、不再做的专案、自己觉得没兴趣的主题

这样看可能还是很模糊，我们对每一块进行举例与说明。

### 1\. 专案

```c
💡 指那些「有時限」以及為了「產出特定成果」的工作，通常是為了達成某個目標 (goal)。
```

**在 PARA 架构中，Projects 是最具有「可行动性(actionable)」笔记。**

例如「在2021 年举办5 场专业技能分享讲座」，就是一个很明确的专案。它包括：

- 有时限：1 年内
- 产出特定成果：举办5 场讲座
- 达成目标：提升自己的专业技能

放在笔记软体中，就是在「Projects」笔记本下方。下图是 Notion 的示意图。

```c
請留意：每種筆記軟體的系統架構都有些不同，這邊我們只要了解具有專案性質的筆記就放在「專案」的資料夾下方即可。
```
![](https://miro.medium.com/v2/resize:fit:1400/format:webp/1*p5TuudRXF7zsmptJzEUTkw.png)

「有时限」以及为了「产出特定成果」的工作笔记，就放在「Project」资料夹下

### 2\. 职责范围（领域）

```c
💡 指那些需要你長時間關注的領域，依據每個人專注的領域而有所不同。
```

这个分类就是我们常说的「主题」。跟 Project 比起来，被分类到 Area 的笔记特性为：

- 没有时间限制
- Area 的层级永远会在 Project 上方
- 「可行动性」比 Project 来的低

例如阅读、写作、课程讲座、健康、个人资料、另一半笔记…等，我们对这些主题很关注，但没有限制自己要在多久时间内完成这些主题，它们没有完成的时间限制。

![](https://miro.medium.com/v2/resize:fit:1100/format:webp/1*0zZU2XvOHXVGx9u_5hJfIQ.png)

我的 Area 分类笔记主题

Tiago Forte 用一张图表示这样的概念：「Product X launch (发布 Product X)」是一个 Project，这个专案是在「Product Development (产品开发)」之下。

![](https://miro.medium.com/v2/resize:fit:1400/format:webp/0*6pFC6p6XP6cJkiYE)

项目与责任范围的关系，图片来源：《 PARA 方法：组织数字信息的通用系统 》

值得一提的是：

> ***这些我们关注、但目前没有「可行动性」的 Areas 笔记，如果有一天个人目标中新增相关的 Project，可以立刻当作参考资料快速推动 Project。***

例如你长期关注「财务报表」这个主题，时常会收集相关的研究、文章、书籍。

这就是将 Projects 和 Areas 笔记分开的好处。平时没有需求，你可以花比较少的时间维护 Areas 的笔记，将精神放在 Projects 的笔记更新上。但是当有需求时，马上就有现成资料可以参考。

### 3\. 资源（资源）

```c
💡 指那些你感興趣的主題、嗜好，但跟自己關注的領域不一定有關。
```

Resources 的「可行动性」比 Projects 和 Areas 还要差，通常看到相关资料都是先收集起来当备用。

以我来说，咖啡、专案管理、音乐、设计、魔术…是我感兴趣的主题，但跟我目前关注的领域没有关联。

要判断一则笔记该归类在 Areas 或 Resources 的原则有 2 个：

**1.关注程度**

问问自己，这则笔记所属的主题，是我目前有花时间好好研究与关心的吗？如果有，那就分类到 Areas; 如果没有，则放到 Resources 之下。

例如「魔术」是我维持长达 10 年以上的兴趣，但是目前我并没有花太多时间研究，因此相关的资料我就会放到 Resources 之下。

**2.隐私性**

这则笔记的内容是否私密只能让自己看见？如果是，那就分类到 Areas; 如果不是(可以分享给其他人)，那就放到 Resources。

例如「专案管理」是我非常关注的主题，但内容不是只有我可以看到，且多数时候我会分享给其他人看，因此相关笔记就可以放到 Resources 之下。

### 4\. 档案（封存）

```c
💡 不屬於以上 3 類，通常是已經做完的專案、不再做的專案、自己覺得沒興趣的主題
```

Archives 是 PARA 中「可行动性」最差的项目，通常被放到 Archives 下的笔记都不具有「可行动性」，只是当作资料留底。

什么样的笔记会被放到 Archives 之下呢？

通常是：

- 已经做完的专案：专案做完了自然就不需要再关注
- 不再做的专案：因为某些原因而不需要做的专案，也不需要再被关注
- 自己觉得没兴趣的主题：如果曾对某一主题有兴趣，但后来确定有很长一段时间再也不会研究了，就可以放到 Archives。

### 5\. PARA 之间的关系

要特别留意，PARA 架构中的笔记是随时可以进行转换的。也就是说：

- Projects 笔记会因为没有时间限制，转变成 Areas; Areas 中的笔记也可以因为需求转变成 Projects 笔记。
- Areas 笔记可以因为近期太多心力关注，转移到 Resources 笔记下; Resources 的笔记能够因为近期突然感兴趣，转移到 Areas 下。

## 三、我使用 PARA 的心得

我在文章的一开头提到了 PARA 的 5 个特点：

- **泛用性** ：适用在任何型态的资源，你不但可以用在笔记软体、也可以用在云端硬碟、个人电脑的档案分类。
- **行动性** ：笔记不再只是死板的资讯，而是可以让你知道下一步的行动是什么。
- **产出导向** ：分类的目标是提升你的产出能力。
- **可缩放性** ：可以让你依据需求调整检视笔记内容的颗粒度，可以快速总览也可以深入细节。
- **可立即开始的** ：可直接从既有的笔记开始使用，不需要大幅颠覆整个既有的笔记系统。

就这5 个特点分享我的使用心得。

### 1\. 泛用性

PARA 不只可以用在笔记软体(Notion)，就连云端硬碟(Google Drive)、Gmail (标签分类) 都可以使用。

### 2\. 行动性

以 Notion 为例，我可以开启 Project 这个分类，就知道自己应该专注在哪些专案笔记上。

### 3\. 产出导向

同样以 Notion 为例，在 Project 下的每个 Page 都是为了产出特定成果的。

例如以「反省日记」为例，其产出成果就是每一天的自我反省与下一步行动。 (模板概念是参考《 [晨间日记的奇迹](https://www.books.com.tw/products/0010317813) 》)

### 4\. 可缩放性

PARA 架构可让我们依据需求，用「快速总览」或「深入细节」的方式来浏览笔记。

第一层只有 Project, Areas, Resources, Archives 4 个项目，如果需要观察目前自己的关注的主题，可再展开检视。

### 5\. 机动性

这是我认为 PARA 最棒的特点：不论你原先的笔记分类如何，都可以立刻开始套用 PARA 架构。

观察这篇文章的 Notion 截图，你可以发现 PARA 下方的分类看起来还是很凌乱。原因是这些分类是我在《 [如何对文件及笔记进行编码分类？结合六个领域的知识来整理笔记](https://medium.com/pm%E7%9A%84%E7%94%9F%E7%94%A2%E5%8A%9B%E5%B7%A5%E5%85%B7%E7%AE%B1/%E5%A6%82%E4%BD%95%E5%B0%8D%E6%96%87%E4%BB%B6%E5%8F%8A%E7%AD%86%E8%A8%98%E9%80%B2%E8%A1%8C%E7%B7%A8%E7%A2%BC%E5%88%86%E9%A1%9E-a25e3f4f92c4) 》时采用的分类，目前套用 PARA 架构后还没有做大幅度的修改。

其实就算不一次修改到位也没关系，因为 PARA 架构最大的特色是区分「可行动性」，最重要的就是 Project 下的笔记，其他 ARA 下的笔记相较就没这么重要。

因此我只要专心顾好 Project 下的笔记即可，其他类型的笔记有空再做调整，不需要强迫自己马上修改。

## 四、总结

这篇文章快速地介绍了 PARA 这套笔记架构，推荐给不知道如何分类笔记的朋友。就算你已经有自己的分类方式，但想要让自己的笔记更有行动力，也可以采用 PARA 的架构做分类。
