# 龙芯稳定性问题统计

> [!info] 说明
> 自动统计 `01-project/龙芯稳定性问题` 目录及其子目录中 `is_issue: true` 的笔记。

## 问题明细

```dataview
TABLE WITHOUT ID
  file.link AS "问题",
  data AS "日期",
  问题分类 AS "问题分类",
  choice(是否定位成功, "✅", "❌") AS "已解决",
  default(instance, "-") AS "实例",
  default(目前结论, "-") AS "目前结论"
FROM "01-project/龙芯稳定性问题"
WHERE is_issue = true
SORT data DESC, file.name ASC
```

## 问题概览

```dataview
TABLE WITHOUT ID
  length(rows) AS "问题总数",
  length(filter(rows, (row) => row.是否定位成功 = true)) AS "已定位",
  length(filter(rows, (row) => row.是否定位成功 != true)) AS "待定位"
FROM "01-project/龙芯稳定性问题"
WHERE is_issue = true
GROUP BY "全部" AS "统计范围"
```

## 问题分类

```dataview
TABLE WITHOUT ID
  key AS "问题分类",
  length(rows) AS "数量"
FROM "01-project/龙芯稳定性问题"
WHERE is_issue = true
FLATTEN default(问题分类, "未分类") AS 分类
GROUP BY 分类
SORT length(rows) DESC
```
