# 标签词表

## Topic

| 标签 | 含义 |
|---|---|
| `topic/virtualization` | 虚拟化通用机制 |
| `topic/kvm` | KVM 实现和接口 |
| `topic/pvm` | PVM 设计、实现和评估 |
| `topic/mmu` | 地址转换、页表和 MMU |
| `topic/nested-virtualization` | 嵌套虚拟化 |

## Activity

| 标签 | 含义 |
|---|---|
| `activity/code-reading` | 源码、论文实现路径阅读 |
| `activity/debugging` | 问题定位和调试过程 |
| `activity/experiment` | 环境搭建、测试和测量 |
| `activity/design` | 架构或方案设计 |
| `activity/howto` | 可重复执行的操作说明 |

## Signal

| 标签 | 含义 |
|---|---|
| `signal/question` | 尚未回答的重要问题 |
| `signal/review` | 需要在复盘中处理 |
| `signal/output` | 可以发展为输出 |

## 规则

- 每篇笔记通常使用 0 到 5 个标签。
- 项目、状态、笔记类型和 MOC 不使用标签表达。
- 新标签预计至少用于 3 篇笔记时才加入本词表。
- `excalidraw` 是插件标签，属于系统例外。

## 非规范标签

```dataview
TABLE WITHOUT ID
  file.link AS "文件",
  tag AS "待整理标签"
FROM "01-project/调研PVM-new"
FLATTEN file.etags AS tag
WHERE tag != "#excalidraw"
  AND !startswith(tag, "#topic/")
  AND !startswith(tag, "#activity/")
  AND !startswith(tag, "#signal/")
SORT tag ASC, file.name ASC
```
